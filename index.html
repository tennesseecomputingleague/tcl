05 Curriculum

What students will learn.

Programming follows a step-by-step path from first line of code to finished project. Theory follows the official ACSL topics, so students are ready to compete.

Programming track

Python · Google Colab
  1. 01Intro to computer scienceWhat CS is and where it shows up in everyday life, plus the basic vocabulary.
  2. 02Algorithms & sequencingAlgorithms as step-by-step instructions. Students write their own for everyday tasks.
  3. 03Intro to programmingVariables, data types and operators, written as real Python in Google Colab.
  4. 04Conditionals & loopsHow programs make decisions with if/else, and repeat work with loops.
  5. 05Functions & abstractionOrganizing code into reusable functions so programs stay clean and short.
  6. 06Build a game or quizStudents make an interactive game or quiz using everything so far.
  7. 07Testing & debuggingCommon errors, how to find them, and how to make code better.
  8. 08Intro to AI modelsHow AI models learn from data, what they can and can’t do, and how to use them responsibly.
  9. 09Build your own AI modelStudents collect data, train a simple model of their own, and test how well it makes predictions.
  10. 10Show & tellReview the big ideas. Students present their projects and explain their code.
